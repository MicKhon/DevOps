# Мой пет-проект

Идея: Telegram-бот `deadlines`, который хранит дедлайны по учёбе и за день напоминает о сдаче. Можно добавить предмет, дату и получить список на неделю командой `/week`.

Стек: Python 3.12 / python-telegram-bot / SQLite / Docker

Цель: научиться писать небольшой сервис с хранением данных и запускать его в контейнере
