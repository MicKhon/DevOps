# Цели на семестр

1. Научиться поднимать сервисы в Docker Compose и понимать, что происходит внутри контейнера, а не только копировать готовые команды.
2. Собрать простой CI на GitHub Actions: проверка репозитория на каждом Pull Request.
3. Освоить базовый Linux (Bash, systemd, ssh), чтобы не бояться работать на удалённой машине.
